## Mission
Design the **best "Benefit"** — a structured incentive delivered inside Solflare/MetaMask wallet UI to 35M monthly active wallets. Winner gets a live placement managed end-to-end by theMiracle with wallet-level conversion analytics.

## What Is a "Benefit"?
A benefit has 4 parts:
1. **Audience** — behavioral user segment (e.g., "DeFi-active Solana wallets")
2. **Action** — one clear action (e.g., "make a first deposit")
3. **Incentive** — reward worth min $5,000 total perceived value distributed across users
4. **Value** — one sentence on what completing the action unlocks

## Submission Requirements
